TNT Walk - Fabric 1.21.11 (Java 21)

Every block you stand on turns into primed TNT. Press F8 to set the fuse time / turn it ON-OFF.

BUILD
  1) Install JDK 21 and Gradle 8.14+  (or run the GitHub Action in .github/workflows)
  2) In this folder run:  gradle build
  3) Jar: build/libs/tntwalk-1.0.0.jar  -> put it in .minecraft/mods with Fabric API (1.21.11)
